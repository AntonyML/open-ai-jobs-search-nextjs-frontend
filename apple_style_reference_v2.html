Apple Design Language

white room · one blue switch · total restraint

Near-white canvas, generous breathing room, one vivid blue accent that makes every action feel deliberate. Typography is the primary voice. The product IS the design.

System

Surface Hierarchy

Elevation without shadows — 3 levels of surface color instead of drop shadows. Flatness is the signature.

Level 0 — Canvas
#f5f5f7
Page background, section default. Never broken by card containers.
Level 1 — Elevated
#f4f8fb
Barely-blue wash for featured product sections.
Level 2 — Pebble
#e2e2e5
Button fills, disabled states, deliberate differentiation.

Guidelines

Rules of the System

The system is opinionated. These are not suggestions.

✓  Do
  • #0071e3 for filled actions only — one color, one job.
  • Pair every filled blue with an outlined secondary. Never stack two filled.
  • 980px radius for every button, tag, pill — non-negotiable.
  • 17px body with -0.016em tracking. The tracking IS the Apple feel.
  • Weight 300 for subheads — the signature whisper voice.
  • Section backgrounds full-bleed #f5f5f7 or a product color wash.
✕  Don't
  • Never use #0071e3 for text, borders, or decoration.
  • Never add drop shadows to cards, buttons, or nav.
  • Never set product names at weight 700 — 600 is the max.
  • Never put a card inside a #f5f5f7 section — canvas IS the surface.
  • Never mix the three blues in one element — fill, outlined, decorative are separate roles.
  • Never use radius below 980px for buttons or above 8px for cards.

Quick Start

CSS Custom Properties

Drop into :root and the full token vocabulary is available.

/* ─── Blues ────────────────────────────── */
--color-apple-blue:  #0071e3; /* filled action only */
--color-link-blue:   #0066cc; /* outlined action, links */
--color-signal-blue: #2997ff; /* decorative borders only */

/* ─── Neutrals ──────────────────────────── */
--color-carbon:   #1d1d1f; /* primary text */
--color-smoke:    #333333; /* secondary text, borders */
--color-graphite: #474747; /* nav text */
--color-ash:      #707070; /* footer text, list borders */
--color-mist:     #858585; /* hairline rules */
--color-pebble:   #e2e2e5; /* button bg, disabled */

/* ─── Surfaces ──────────────────────────── */
--color-frost:    #f5f5f7; /* page canvas */
--color-ice:      #f4f8fb; /* elevated wash */

/* ─── Radius ────────────────────────────── */
--radius-button: 980px;
--radius-card:   8px;

/* ─── Typography ────────────────────────── */
--font-display: 'SF Pro Display', ui-sans-serif, system-ui;
--font-text:    'SF Pro Text', ui-sans-serif, system-ui;

/* ─── Shadow (product image only) ───────── */
--shadow-product: rgba(0,0,0,.22) 3px 5px 30px 0px;
